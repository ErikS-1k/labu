# Labu

Marketplace que conecta personas que ofrecen y buscan servicios independientes: desde profesores particulares hasta oficios y servicios creativos.

🔗 [labu-six.vercel.app](https://labu-six.vercel.app)

## Stack

Next.js 16 · React · TypeScript · Tailwind CSS v4 · Supabase · Vercel

## Features principales

- Búsqueda con Full Text Search + tolerancia a typos
- Chat en tiempo real
- Notificaciones push (PWA)
- Modo claro/oscuro
- Verificación de identidad
- Sistema de opiniones
- Panel admin con métricas

## Setup local

```bash
git clone https://github.com/ErikS-1k/labu.git
cd labu
npm install
cp .env.example .env.local  # completar con credenciales de Supabase
npm run dev
```
